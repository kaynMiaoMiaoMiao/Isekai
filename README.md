## 简介
Make Isekai great again!

异界幻想生物（Isekai Creatures）是 Minecraft 1.20.1 的 Fabric 模组，加入了坐骑「陆行鸟」、刷怪蛋、孵化蛋和格拉姆硬币。

## 陆行鸟

- 陆行鸟会在主世界自然生成，不同颜色分布在不同群系（默认值，可在配置文件修改）：
  - 橙红：沙漠、恶地、热带草原
  - 深蓝：针叶林、原始松木/云杉针叶林、风袭丘陵
  - 粉棕：樱花树林、草甸
  - 翠绿：平原、向日葵平原、森林、繁花森林、桦木森林、稀疏丛林
  - 墨黑：黑森林、沼泽、红树林沼泽
  - 银蓝：雪原、积雪针叶林、冰刺之地、雪林
- 也可以在「异界幻想生物」创造模式标签页使用「陆行鸟刷怪蛋」，或用 `/summon isekai:land_bird` 召唤。`/summon isekai:land_bird ~ ~ ~ {Plumage:6}` 可指定颜色。
- 手持胡萝卜右键野生陆行鸟，每根有 15% 概率驯服（可配置）；失败会冒烟。驯服的成年陆行鸟可骑乘，装上马鞍后可以控制移动和跳跃。骑乘时正常前进是「行走」（默认为疾跑速度的 40%，可配置），按疾跑键（或双击前进）是「疾跑」（满速）。骑乘疾跑不受饥饿值限制，撞墙或松开前进键会停止疾跑。上鸟后按背包键可打开坐骑装备栏。
- 喂食：胡萝卜给受伤的陆行鸟 10 秒生命恢复（可叠加到 60 秒）；金胡萝卜直接回满血。给驯服的幼鸟喂胡萝卜或金胡萝卜，每次让它提前 50 秒长大。
- 手持胡萝卜或金胡萝卜可以引诱附近清醒的陆行鸟。成鸟装备马铠会显示对应材质，皮革马铠支持染色。
- 已驯服的幼鸟和成鸟都能由主人潜行右键切换游荡、坐下、跟随，动作栏会显示当前状态。野生幼鸟在游荡时会跟随附近的成鸟。
- 跟随模式下，陆行鸟离主人超过 12 格会传送到主人身边。
- 陆行鸟入夜会坐下休息，天亮后恢复原来的状态。跟随模式下，主人在夜里移动时它会一直跟着，主人停下（或上床睡觉）约 3 秒后才入睡。
- 夜里被打的陆行鸟会醒来逃离攻击者，直到附近没有攻击者和怪物后再入睡。主人命令「坐下」的陆行鸟会原地不动。
- 陆行鸟有六种外观，幼鸟约 20 分钟后会长成同色成鸟。
- 分别给两只成年陆行鸟喂金胡萝卜，它们会在原地掉落一颗随机颜色的蛋。

## 孵化蛋

- 「异界幻想生物」创造模式标签页有六种颜色的陆行鸟蛋，生存模式可通过繁殖获得。
- 放下蛋后，在三格距离内有点燃的营火、火、灵魂火、熔岩或岩浆块时会累计孵化时间。远离热源会暂停，累计达到设定时长后会孵出同色幼鸟，蛋上方需要留出空间。
- 空手右键蛋可以查看状态：孵化进度和剩余时间、缺少热源，或者蛋上方被挡住无法破壳。
- 受热时蛋会循环晃动，暂停孵化时会静止。孵化完成前会播放破壳动画。
- 第一位右键与孵化幼鸟互动的玩家会成为它的主人。

## 配置

首次启动会生成 `config/isekai.properties`，旧版配置文件会自动补上新增的项并保留原有的值。修改后重启游戏生效；联机时改服务端的配置。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `eggIncubationSeconds` | 1200 | 孵化需要的受热秒数（20 分钟） |
| `tameChancePercent` | 15 | 每根胡萝卜驯服野生陆行鸟的概率（0-100） |
| `ridingWalkSpeedPercent` | 40 | 骑乘不按疾跑时的速度，占疾跑速度的百分比（1-100） |
| `spawnWeight` | 3 | 自然生成权重，0 为关闭（马在平原是 5） |
| `spawnMinGroupSize` / `spawnMaxGroupSize` | 1 / 3 | 每群数量 |
| `plumage1Biomes` … `plumage6Biomes` | 见上 | 各颜色的生成群系，用逗号分隔群系 ID 或 `#群系标签`，留空则该颜色不自然生成 |

## 构建

使用 JDK 17 或 21。在 Windows 上运行 `./gradlew.bat build`，在 Linux 或 macOS 上运行 `./gradlew build`。产物位于 `build/libs/`，游戏运行时还需要 Fabric API 和 GeckoLib。
